# Phase 2 Production Readiness — Deterministic AI Pathfinding

Phase 2 is production-ready only when every gate below is satisfied on the exact merge candidate and again on the merged `main` commit.

## Scope delivered

- Framework-independent `@snake/ai` package.
- Immutable AI observations derived from authoritative engine state.
- Deterministic orthogonal board graph with canonical neighbor ordering.
- BFS shortest-path search and reusable distance maps.
- Deterministic A* with Manhattan heuristic and stable tie-breaking.
- Food target planning across multiple targets.
- Current-tail route planning with explicit tail-cell traversal semantics.
- Deterministic candidate-move legality and distance ranking.
- Search telemetry based on deterministic operation counts.
- Optional elapsed-time measurement only through an injected clock.
- Headless deterministic AI smoke runner.
- Large-board bounded-search tests.

## Determinism invariants

- Search must never call `Math.random()`, wall-clock APIs, browser APIs, timers, or storage APIs.
- Canonical neighbor order is `up`, `right`, `down`, `left`.
- Repeated identical observations and targets must return deep-equal search results.
- Search timing must not affect path selection or deterministic telemetry.
- Engine state must remain unmodified by observation creation or search.

## Correctness gates

Automated tests cover:

- observation projection and reference isolation;
- body, obstacle, hazard, and board-edge blocking;
- explicit traversable target behavior;
- BFS canonical shortest routes, detours, invalid targets, unreachable targets, zero-length routes, and distance maps;
- A* shortest-path equivalence and deterministic tie handling;
- multiple-food selection with deterministic tie rules;
- current-tail planning;
- reversal, blocked-move, and vacating-tail candidate legality;
- deterministic candidate ranking;
- injected timing;
- repeated search equality;
- 100×100 operation bounds.

## Build and dependency gates

The release candidate must pass:

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm check:forbidden
pnpm headless
pnpm headless:ai
```

`pnpm-lock.yaml` must include the `packages/ai` workspace importer and be generated by pnpm 10.15.0.

## CI gates

GitHub Actions must verify:

1. frozen dependency installation;
2. strict TypeScript typecheck across all workspaces;
3. all Phase 1 and Phase 2 tests;
4. production package builds;
5. forbidden nondeterministic/browser API scan across `shared`, `engine`, and `ai` sources;
6. two engine headless executions with byte-identical output;
7. two AI headless executions with byte-identical output.

## Architectural gates

- `@snake/engine` must not depend on `@snake/ai`.
- `@snake/ai` may consume engine types/read-only observations but must not own simulation state.
- Rendering, React, PixiJS, DOM, OBS, and UI types must not enter the AI package.
- Phase 3 survival reasoning — flood fill, future-state simulation, trap scoring, food-safety rejection, risk scoring, Hamiltonian routing, and hybrid strategy switching — remains intentionally absent.

## Release procedure

1. Exact PR head passes the full frozen CI gate.
2. Final diff is reviewed for scope, deterministic behavior, mutation leaks, and performance regressions.
3. Branch is confirmed not behind `main`.
4. PR is squash-merged using an expected-head SHA guard.
5. The resulting `main` commit passes the same permanent CI workflow.

Only after step 5 may Phase 2 be marked production-ready and Phase 3 begin.
