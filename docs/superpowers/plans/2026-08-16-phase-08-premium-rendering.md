# Phase 8 Premium Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-grade PixiJS presentation layer for the autonomous Snake simulation with smooth interpolation, premium skins/themes/effects, deterministic snapshot projection, bounded resources, a browser preview host, and release-quality validation at 1080p/1440p/4K.

**Architecture:** Add `@snake/renderer` as a presentation-only workspace package. It consumes immutable public simulation/engine data through a pure `RenderFrame` projection, owns all Pixi scene objects and render timing, and exposes an explicit lifecycle API. Add a minimal `apps/render-preview` Vite browser host for visual/resolution verification without allowing browser/renderer timing to feed back into simulation state.

**Tech Stack:** TypeScript 5.8.3, PixiJS 8.19.0, Vite 7.x preview host, Vitest 3.2.4, pnpm 10.15.0, Node.js 22+.

## Global Constraints

- Rendering must never advance authoritative simulation state or mutate `GameState`.
- PixiJS frame timing/FPS must never influence gameplay, AI, failure probability, progression, or records.
- No React rerender per snake segment/tick; Phase 8 uses Pixi directly.
- All transient pools and rolling metrics must be hard-bounded.
- Target layouts: 1920×1080, 2560×1440, 3840×2160.
- Seven skins: Emerald, Neon, Inferno, Galaxy, Gold, Rainbow, Void.
- Initial themes: Neon Grid, Digital Forest, Volcano, Arctic, Cyber City, Desert, Deep Ocean, Space, Matrix, Ancient Temple, Cosmic Void.
- Required quality presets: Performance, Balanced, Cinematic.
- Unknown theme/skin values fall back to explicit defaults and surface a renderer warning.
- `destroy()` must be idempotent and release renderer-owned ticker hooks, display objects, pools, frame references, and generated resources.
- The preview host is development/verification infrastructure, not the Phase 9 livestream HUD or Phase 10 operator dashboard.

- `package.json` — workspace package metadata and PixiJS dependency.
- `tsconfig.json` — strict TypeScript build.

- `src/frame.ts` — pure immutable engine/simulation → `RenderFrame` projection and validation.
- `src/interpolation.ts` — previous/current frame interpolation, turn handling, discontinuities.
- `src/viewport.ts` — 16:9 viewport and board coordinate transforms.
- `src/skins.ts` — seven data-driven snake skin definitions/registry.
- `src/themes.ts` — eleven environment theme definitions/registry.
- `src/quality.ts` — Performance/Balanced/Cinematic presets.
- `src/pool.ts` — generic bounded reusable-object pool.
- `src/metrics.ts` — bounded frame-time metrics.
- `src/events.ts` — spectator-safe event dedupe/TTL presentation state.
- `src/scene.ts` — Pixi layer/container construction and z-order ownership.
- `src/draw-board.ts` — background/grid/active-bound rendering.
- `src/draw-snake.ts` — pooled/reused snake geometry and head/body/trail presentation.
- `src/draw-items.ts` — food/item presentation.
- `src/draw-environment.ts` — obstacles/hazards/portals.
- `src/effects.ts` — capped transient effect pools.
- `src/renderer.ts` — public `SnakeRenderer` lifecycle and frame update orchestration.
- `src/index.ts` — public exports.

- `package.json` — Vite browser package.
- `tsconfig.json` — browser TS config.
- `index.html` — preview mount.
- `src/main.ts` — deterministic demo feed and renderer initialization.
- `src/style.css` — preview-only chrome/background.

- `packages/renderer/src/*.test.ts` colocated with pure modules.
